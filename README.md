# StudentShare

StudentShare is a college-specific student notes-sharing web application.

## Features

- College management
- Admin accounts
- Supervisor accounts
- Student accounts
- Course management
- Semester management
- Subject management
- Study material upload
- PDF and PPT support
- Question paper sharing
- Material ratings
- Material filtering
- User approval system

## Technology Used

- Java
- JSP
- Servlets
- HTML
- CSS
- JavaScript
- MySQL
- GlassFish 7
- Maven
- NetBeans

## User Roles

### Admin
Manages the college, courses, semesters, subjects and users.

### Supervisor
Manages materials for the assigned course.

### Student
Views, uploads and rates study materials.
